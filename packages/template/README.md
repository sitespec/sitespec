# @sitespec/template

The default standalone SiteSpec website template. It is the shared scaffold used by both `@sitespec/create` and `sitespec init`.

The v0.2 starter is intentionally an executable contract showcase rather than a component gallery. It includes UI primitives, reusable section presets, deterministic dynamic routes with route-parameter references, named navigation references, the pagination core type, a local WOFF2 font, semantic site assets, the user-owned Site Shell, semantic design tokens, and agent inspection examples.
