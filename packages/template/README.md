# @sitespec/template

The default SiteSpec v0.5 starter is an executable contract showcase rather than a component gallery. It includes typed Markdown content, content-driven routes and query pagination alongside a first-class portable Design System contract, themes, UI primitives, reusable section presets, explicit dynamic routes with route-parameter references, named navigation references, local WOFF2 fonts, semantic site assets, the selectable shell packs, semantic design tokens with controlled site extensions, and agent inspection examples.

The starter intentionally keeps content small: one `posts` collection, two Markdown entries, one listing page and one entry page. Richer relation/filter/taxonomy patterns live in `examples/marketing`.
